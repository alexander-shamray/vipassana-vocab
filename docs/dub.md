# Русская озвучка уроков: как повторить всё самому

Эта инструкция ведёт от чистого компьютера до готового урока: видео с Гоенкой и отдельные аудиодорожки, у каждой своя громкость и отключение. Все команды выполняются в PowerShell.

Озвучка только для личного прослушивания. Причины в разделе [Лицензии и авторские права](#лицензии-и-авторские-права).

## Что получится

В папке `data/dub-pilot/lesson<N>/`:

| Файл | Что это |
|---|---|
| `index.html` | плеер: видео и галочка с ползунком на каждую дорожку |
| `video.mp4` | видео без звука |
| `english.m4a` | Гоенка, оригинал |
| `narrator.m4a` | живой русский диктор с YouTube, подогнанный под английское время |
| `silero-eugene.m4a` | синтез Silero, голос eugene |
| `xtts-clone.m4a` | синтез XTTS, клон голоса Гоенки |
| `lesson<N>.mkv` | всё то же одним файлом, для VLC |
| `tracks.json` | список дорожек и цифры подгонки |

VLC играет только одну аудиодорожку за раз. Смешивать голоса можно только в плеере. Там же можно развести их по наушникам: оригинал слева, русские голоса справа.

## Карта шагов

Время указано для урока длиной около 75 минут на видеокарте RTX A5500 с 16 ГБ памяти.

| № | Команда | Что делает | На чём | Время | Цена |
|---|---|---|---|---|---|
| 0 | `dub ref` | вырезает образец голоса для клона, один раз на все уроки | Go, ffmpeg | секунды | — |
| 1 | `dub fetch N` | скачивает английское видео и русскую дорожку | Go, yt-dlp | ~2 мин | — |
| 2 | `dub whisper N` | распознаёт русского диктора с временем каждого слова | Python, Whisper | ~8 мин | — |
| 3 | `dub script N` | Claude чистит текст, ставит ударения, сопоставляет фразы с английскими | Go, Claude | ~6 мин | $3–4 |
| 4 | `dub accent N` | второе мнение об ударениях | Python, RuAccent | ~1 мин | — |
| 5 | `dub review N` | показывает новые разногласия по ударениям | Go | секунды | — |
| 6 | `dub marks N` | итоговые ударения | Go | секунды | — |
| 7 | `dub silero N` | озвучка Silero | Python, Silero | ~1 мин | — |
| 8 | `dub xtts N` | озвучка XTTS, проверка Whisper, новые дубли плохих фраз | Python, XTTS, Whisper | ~1 ч 10 мин | — |
| — | `dub retake N <номера>` | новый дубль выбранных фраз XTTS | Python, XTTS, Whisper | секунды на фразу | — |
| — | `dub find N <слово>` | номера и текст фраз с этим словом | Go | секунды | — |
| 9 | `dub fit N` | укладывает дорожки на английское время, собирает файлы | Go, ffmpeg | ~5 мин | — |
| 10 | `dub page N` | пишет страницу плеера | Go | секунды | — |
| 11 | `dub serve` | открывает плееры для телефона по Wi-Fi | Go | — | — |

`dub run N` выполняет шаги 0–10 по порядку и пропускает уже сделанное. Шаг 5 он не показывает: его стоит запускать отдельно, если важны ударения. Шаг 8 считается сделанным только после последнего раунда дублей, а шаги 9 и 10 повторяются, если появился новый голос или изменились фразы.

Перед первым запуском нужно установить всё из следующего раздела.

## Установка с нуля

Этот раздел собран из того, что реально стоит на рабочей машине, но целиком на чистом компьютере не проверялся. Версии указаны те, на которых всё работало.

### Что нужно заранее

| Что | Зачем | Проверка |
|---|---|---|
| Windows 11 и видеокарта NVIDIA, от 12–16 ГБ | Whisper и XTTS на процессоре работают очень медленно | `nvidia-smi` |
| Go 1.27 или новее | команда `dub` | `go version` |
| Python 3.12 | модели | `py -3.12 --version` |
| Git | код Silero | `git --version` |
| Ключ Anthropic | шаг 3 | переменная `ANTHROPIC_API_KEY` |
| Диск: около 25 ГБ на модели и окружения, ~1,2 ГБ на урок | | |

### 1. Основной конвейер: английский текст и звук

Озвучка берёт английскую расшифровку и звук из конвейера словаря.

```powershell
cd pipeline
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[run,dev]"
.venv\Scripts\python -m pip install soundfile==0.14.0
.venv\Scripts\python -m vv_pipeline fetch --only 1,4
.venv\Scripts\python -m vv_pipeline transcribe --only 1,4
cd ..
```

Появятся `data/audio/<id>.m4a` и `data/transcripts/<id>.json`. Урок 1 нужен всегда: из него берётся образец голоса. Модель Whisper large-v3 скачается сама при первом запуске, около 3 ГБ. Подробнее в [pipeline/README.md](../pipeline/README.md).

### 2. Команда dub

```powershell
cd dub
go build -o bin\dub.exe .
go test .
cd ..
```

Дальше все команды запускаются из корня репозитория как `dub\bin\dub.exe ...`, а рабочая папка по умолчанию `data\dub-pilot`.

### 3. Рабочая папка и ffmpeg

```powershell
New-Item -ItemType Directory -Force data\dub-pilot\bin | Out-Null
cd data\dub-pilot
py -3.12 -m venv .venv-tools
.venv-tools\Scripts\python -m pip install uv imageio-ffmpeg
.venv-tools\Scripts\python -c "import imageio_ffmpeg, shutil; shutil.copy(imageio_ffmpeg.get_ffmpeg_exe(), 'bin/ffmpeg.exe')"
```

Если ffmpeg уже есть в `PATH`, копия в `bin` не нужна.

### 4. Окружения моделей

У каждой модели своё окружение, потому что их зависимости конфликтуют. Команды выполняются в `data\dub-pilot`.

```powershell
$uv = ".venv-tools\Scripts\uv.exe"
$cuda = "https://download.pytorch.org/whl/cu128"

# Silero
& $uv venv --python 3.12 .venv-main
& $uv pip install --python .venv-main\Scripts\python.exe torch==2.11.0 torchaudio==2.11.0 --index-url $cuda
& $uv pip install --python .venv-main\Scripts\python.exe omegaconf==2.4.0 soundfile==0.14.0 scipy==1.18.1

# XTTS
& $uv venv --python 3.12 .venv-xtts
& $uv pip install --python .venv-xtts\Scripts\python.exe torch==2.11.0 torchaudio==2.11.0 --index-url $cuda
& $uv pip install --python .venv-xtts\Scripts\python.exe coqui-tts==0.28.0 soundfile==0.14.0 six==1.17.0 torchcodec==0.17.0

# RuAccent
& $uv venv --python 3.12 .venv-accent
& $uv pip install --python .venv-accent\Scripts\python.exe ruaccent==1.5.8.3 "transformers<4.50"
```

### 5. Модели

**Silero.** Код и модель хранятся локально, поэтому сбой GitHub больше не остановит работу. Файл `v5_ru.pt` скачается сам при первом запуске:

```powershell
git clone --depth 1 https://github.com/snakers4/silero-models models\torchhub\snakers4_silero-models_master
```

**XTTS.** Модель, около 2 ГБ, скачается при первом запуске `dub xtts`. Сначала она спросит, принимаете ли вы лицензию: прочитайте её и ответьте сами. Ответ запоминается в `models\tts`.

**RuAccent.** Словарь и модель скачаются при первом запуске `dub accent`.

Вернитесь в корень репозитория: все дальнейшие команды запускаются оттуда.

```powershell
cd ..\..
```

### 6. Ключ Claude

Ключ нужен только для шага 3. Читается из переменной окружения. Не записывайте его в файлы репозитория. Сохраните его один раз, затем откройте новый терминал:

```powershell
[Environment]::SetEnvironmentVariable('ANTHROPIC_API_KEY', '<ваш ключ>', 'User')
```

Без ключа `dub script` сразу остановится с понятным сообщением.

## Шаги подробно

Примеры даны для урока 4. Уроки 1–11 уже описаны в `dub/lessons.go`.

### Шаг 0. Образец голоса: `dub ref`

XTTS клонирует голос по короткому образцу. Команда ищет в английской беседе первого дня отрезок около 25 секунд с самой плотной речью: не раньше пятой минуты и без сегментов, в которых Whisper сомневается. Затем звук переводится в моно 24 кГц и очищается фильтрами `highpass=f=70,lowpass=f=9000`.

Результат: `ref/ref25.wav` и текст образца `ref/ref25.txt`. Послушайте файл: в нём должен быть только голос, без музыки и чужих шумов.

### Шаг 1. Скачивание: `dub fetch 4`

Скачиваются два файла в `work4/`:

- `en-video-480.mp4`: только картинка, формат YouTube 135 (H.264, 480p);
- `ru-audio.m4a`: только звук русского диктора.

**Осторожно с дорожками.** У русских видео YouTube появился автодубляж на английском, причём под похожими номерами форматов. Формат `140-1` у урока 4 оказался английским автодубляжом, а русский — `140-3`. Поэтому команда просит дорожку по языку: `ba[ext=m4a][language^=ru]`. Проверить можно так:

```powershell
pipeline\.venv\Scripts\yt-dlp -F "https://www.youtube.com/watch?v=VQCfCIyVXTE"
```

### Шаг 2. Распознавание: `dub whisper 4`

Whisper large-v3 с параметрами `language='ru'`, `word_timestamps=True`, `condition_on_previous_text=False`. Последний отключает зацикливание на выдуманном тексте.

Результат: `work4/ru-transcript-full.json`. Обязательно посмотрите начало файла: текст должен быть на русском. В конце нормально встретить «Субтитры создавал DimaTorzok»: Whisper выдумывает такие титры в тишине, следующий шаг их удалит.

### Шаг 3. Текст и сопоставление: `dub script 4`

Сначала команда режет слова на фразы по концу предложения, паузам и длине: не больше 145 символов, чтобы хватало XTTS. Сегменты, в которых сомневается сам Whisper, отбрасываются. Если в тексте меньше 90% кириллицы, команда останавливается ещё до обращения к Claude: это значит, что скачана не та дорожка.

Дальше два запроса к Claude (модель `claude-opus-5-5`):

1. **Чистка и ударения.** Пакеты по 50 фраз, четыре запроса одновременно. Claude исправляет только ошибки распознавания, записывает числа словами, а термины пали кириллицей, ставит ё и ударения. Готовые пакеты сохраняются в `full-stress-cache.json`, поэтому прерванный запуск продолжается без повторной оплаты.
2. **Сопоставление.** Для каждой русской фразы Claude указывает английскую, где начинаются те же слова. Результат в `full-align.json`.

Результат: `full-en.json` (английские фразы) и `full-ru.json` (русские). Обошлось в $3,82 за урок 1 и $3,12 за урок 4.

Повторный запуск удаляет результаты шагов 4 и 6, потому что они сделаны из старого текста. Если текст изменился, удалите и `out-full`, иначе останется старая озвучка.

### Шаг 4. Второе мнение: `dub accent 4`

RuAccent (словарь и модель омографов) размечает тот же текст. Результат: `full-ru-accent.json` и `accent-diff.json` со всеми разногласиями.

### Шаг 5. Проверка: `dub review 4`

Показывает разногласия, которых не было в других уроках:

```
Claude: п+осле     RuAccent (it wins): посл+е     times: 1
```

По умолчанию побеждает RuAccent. На 137 спорных формах урока 1 Claude ошибался чаще: «реальн+ость», «вн+утри». Но и RuAccent ошибается: «посл+е», «к+акая-то». Когда он неправ, допишите верную форму в `dub/stress-fixes.json`. Сверяйтесь со словарём, например с Викисловарём или gramota.ru.

Это необязательный шаг, но он убирает самые заметные ошибки. Слова, в которых ошиблись оба, он не покажет: их можно найти только на слух.

### Шаг 6. Итоговые ударения: `dub marks 4`

Порядок для каждого слова: `dub/stress-fixes.json`, затем RuAccent, затем Claude. Кроме этого команда:

- убирает ударения в словах с одной гласной и с ё;
- убирает невидимые символы и запинки диктора («это это», «с с»);
- удаляет пустые фразы, оставшиеся от выдуманных титров.

Оригинал Claude сохраняется в `full-ru.claude.json`. Результат: окончательный `full-ru.json`.

### Шаг 7. Silero: `dub silero 4`

Голос `eugene`, 48 кГц, с настройками:

```python
put_accent=True, put_yo=False, put_stress_homo=False, put_yo_homo=False
```

Слова с нашими `+` Silero не трогает, а остальным ставит ударение сам. Важен именно `put_accent=True`: без него односложные слова остаются безударными, и фраза затухает («как+ое он+о есть» с понижением на «есть»).

Результат: `work4/out-full/silero-eugene/0000.wav` и далее. Готовые фразы при повторном запуске пропускаются.

### Шаг 8. XTTS: `dub xtts 4`

Самый долгий шаг. Внутри него четыре этапа:

1. **Озвучка всех фраз** из `ref/ref25.wav`, ~35–40 мин. Каждые 25 фраз печатается строка вида `25 of 784`. Можно прервать и продолжить.
2. **Проверка.** Whisper отдельно слушает каждую фразу и сравнивает с текстом, ~10 мин. Результат: `check-xtts-clone.json`.
3. **Выбор подозрительных.** В список попадают фразы с двумя и больше ошибками или с лишними словами. У XTTS есть дефект: в конце фразы иногда появляется посторонний слог, например «дыхание Эджи», а короткая фраза может зациклиться. Кавычки он тоже озвучивает посторонним слогом («Нет» превращается в «Я нет»), поэтому в его текст они не попадают.
4. **Новые дубли.** Четыре раунда, ~25 мин. Каждый дубль получает новый номер и случайный сид, остаётся дубль с наименьшим числом ошибок. Первая версия каждой заменённой фразы сохраняется в `out-full/xtts-original/`, все дубли в `out-full/xtts-takes/`. Повторный `dub xtts` запускает ещё четыре раунда для оставшихся подозрительных фраз.

На уроке 1 это снизило ошибки распознавания с 5,8% до 2,3%. Whisper ошибается и сам, особенно на цифрах, поэтому часть оставшихся подозрений ложные.

**Ударения в XTTS задать нельзя.** В его словаре нет знака ударения: `+` и U+0301 превращаются в неизвестный символ, а запись гласных «как слышится» даёт акцент. Поэтому текст идёт как есть, и неверное ударение может остаться. Интонацией модель тоже управлять не позволяет.

### Шаг 9. Подгонка: `dub fit 4`

Английская запись считается главной: картинка и звук Гоенки не меняются. Для каждой русской дорожки:

1. Цель фразы: момент начала сопоставленной английской фразы.
2. Фраза ставится на цель или сразу после предыдущей, если та ещё не закончилась. Пауза между фразами 0,12 с.
3. Темп плавно растёт от объёма текста в ближайшие 60 секунд и от текущего опоздания:
   `темп = max(текст/время, 1) + опоздание/120`, не больше 1,25.
4. Темп меняет `atempo`: скорость растёт, высота голоса сохраняется.
5. Громкость каждой дорожки приводится примерно к −20 дБ, чтобы ползунки начинали с одного уровня.

У синтеза вокруг фразы обрезается тишина. Диктор нарезается по времени распознанных слов с короткими затуханиями.

`dub fit -stats 4` считает цифры, ничего не записывая. В `tracks.json` они называются так:

| Поле | Значение |
|---|---|
| `tempo_mean` | среднее ускорение |
| `tempo_at_cap` | сколько фраз упёрлось в предел 1,25 |
| `late_median_s`, `late_p90_s`, `late_max_s` | опоздание от английской фразы: медиана, 90% фраз, максимум |

### Шаг 10. Плеер: `dub page 4`

Видео идёт без звука, а аудиодорожки следуют за его временем: каждые 0,4 с небольшое расхождение выравнивается скоростью, а больше 0,3 с — прыжком. Настройки хранятся в браузере отдельно для каждого урока.

**Разделение по наушникам.** Галочка под дорожками отправляет оригинал в левый наушник, а все русские голоса в правый. Она включена по умолчанию и работает через Web Audio. Браузер запрещает такую обработку для файлов, открытых двойным щелчком, поэтому там галочка недоступна: откройте плеер через `dub serve`.

Без разделения страницу можно открыть двойным щелчком:

```powershell
start data\dub-pilot\lesson4\index.html
```

### Шаг 11. С телефона по Wi-Fi: `dub serve`

```powershell
dub\bin\dub.exe serve
```

Команда напечатает адрес вроде `http://192.168.1.110:8765/`. Откройте его на телефоне в той же сети, остановка — `Ctrl+C`.

- При первом запуске Windows спросит разрешение: разрешите только для частных сетей.
- Пароля нет: пока сервер работает, страницу может открыть любой в этой сети. Отдаются только файлы плееров.
- На Android (Chrome) всё должно работать. На iPhone ползунки работают только с включённым разделением по наушникам: без него iOS не даёт странице менять громкость. С настоящими телефонами плеер не проверялся.

## Перекодировка видео и звука

**Видео не перекодируется.** Это сохраняет качество и занимает секунды, а не часы.

| Дорожка | Откуда | Обработка | Итог |
|---|---|---|---|
| Видео | YouTube, формат 135 | копия без звука (`-an -c:v copy`), индекс в начало файла (`-movflags +faststart`) | H.264, 480p, 25 к/с |
| Английский звук | `data/audio/<id>.m4a` | копия (`-c:a copy`) | AAC, 44,1 кГц, стерео |
| Русские дорожки | фразы, разложенные в шаге 9 | кодирование `-c:a aac -b:a 96k` | AAC, 48 кГц, моно, 96 кбит/с |
| `.mkv` | все файлы выше | только упаковка (`-c copy`), подписи и язык дорожек | ~290 МБ на урок |

Посмотреть, что внутри:

```powershell
data\dub-pilot\bin\ffmpeg.exe -hide_banner -i data\dub-pilot\lesson4\lesson4.mkv
```

Если нужно другое качество, это можно сделать так. Эти команды я не запускал, проверьте результат:

- **Больше разрешение.** Замените формат `135` в `runFetch` файла `dub/main.go`, например на `136` (720p), и удалите `work4/en-video-480.mp4`.
- **Меньше размер.** Перекодируйте готовое видео, это займёт время и немного ухудшит картинку:

  ```powershell
  data\dub-pilot\bin\ffmpeg.exe -i data\dub-pilot\lesson4\video.mp4 -c:v libx264 -crf 30 -preset slow -movflags +faststart data\dub-pilot\lesson4\video-small.mp4
  ```

  После этого замените им `video.mp4`.

## Правки после прослушивания

**Неверное ударение в Silero:**

1. Допишите слово в `dub/stress-fixes.json`, например `"п+осле"`.
2. Обновите разметку: `dub\bin\dub.exe marks 4`.
3. Удалите озвучку, чтобы фразы создались заново. Silero работает быстро, поэтому проще всю папку: `Remove-Item -Recurse data\dub-pilot\work4\out-full\silero-eugene`.
4. Выполните `dub silero 4`, `dub fit 4` и, если менялись дорожки, `dub page 4`.

Список общий для всех уроков. На уроках, собранных раньше, правка подействует только после повторения этих шагов.

**Лишний звук в XTTS.** Найдите номера фраз и запросите новый дубль, он заменит текущий:

```powershell
dub\bin\dub.exe find 4 дыхание
dub\bin\dub.exe retake 4 58 242
dub\bin\dub.exe fit 4
```

Новый дубль будет другим, но не обязательно лучше. Прежняя версия остаётся: первая в `out-full/xtts-original/`, следующие в `out-full/xtts-takes/`. Подозрительные фразы перечислены в поле `still` файла `work4/check-xtts-clone.json`. Лишний файл удалять не нужно, а без `retake` это ещё и опасно: копии может не быть.

**Неверное ударение в XTTS.** Управлять им нельзя. Обойти можно только переписыванием слова так, как оно слышится, и только этого слова. Допишите его в `dub/xtts-respell.json`:

```json
{ "фонема": "фанема" }
```

Затем запросите новые дубли фраз с этим словом через `dub find` и `dub retake`, как выше. Silero и проверка Whisper этот список не используют, а `dub marks` его не затирает. Не правьте для этого `full-ru.json`: `dub marks` перезапишет файл.

## Если что-то пошло не так

| Симптом | Причина | Что делать |
|---|---|---|
| `the narration is not Russian` или английский текст в расшифровке | скачан автодубляж | удалить `ru-audio.m4a` и расшифровку, проверить форматы, скачать заново |
| `HTTP Error 504` при загрузке Silero | старый способ загрузки обращался к GitHub | использовать `dub silero`: он работает с локальной копией |
| Silero ставит понижение на «есть» | `put_accent=False` | оставить настройки из шага 7 |
| XTTS завис без вывода | он спрашивает про лицензию, а вывод скрыт | запускать как `dub xtts` и ответить |
| `No module named 'six'` в XTTS | пропущена зависимость | поставить `six==1.17.0` |
| Ошибка загрузки DLL `torchcodec` | нет нужных библиотек FFmpeg | ничего: скрипт читает звук через `soundfile` в обход |
| Ошибка про `token_type_ids` в RuAccent | слишком новый transformers | `transformers<4.50` |
| Whisper повторяет один и тот же текст | зацикливание | `condition_on_previous_text=False`, уже стоит |
| `no answer for phrases` на шаге 3 | Claude не ответил на пакет | запустить снова, готовые пакеты не оплачиваются повторно |
| `ANTHROPIC_API_KEY is not set` | нет ключа | раздел «Ключ Claude» |
| `No module named 'scipy'` в Silero | пропущена зависимость | поставить `scipy==1.18.1` в `.venv-main` |
| `No module named 'soundfile'` после озвучки XTTS | пропущена зависимость конвейера | поставить `soundfile==0.14.0` в `pipeline\.venv`, запустить `dub xtts` снова: фразы сохранены |
| `WARNING: ... has no audio for phrases` | фразы не озвучились | запустить `dub silero` или `dub xtts` снова, затем `dub fit` |
| `-home` не работает | рабочая папка должна лежать на два уровня ниже корня репозитория | оставить `data\dub-pilot` |
| Телефон не открывает страницу | брандмауэр или сеть отмечена общедоступной | разрешить для частных сетей или сменить тип сети |
| Плеер не играет с `file://` | ограничения браузера | запустить `dub serve` и открыть `http://localhost:8765/` |
