# Vipassana Vocab: словарь бесед Гоенки — проектный документ

Дата: 2026-11-07. Статус: черновик на согласование владельцем.

## 1. Зачем это

Владелец слушает «10 Day Vipassana Discourses (English)» С. Н. Гоенки
(плейлист YouTube `PLPJVlVRVmhc4Z01fD57jbzycm9I6W054x`, около 11 вечерних бесед
по ~1–1,5 часа) и хочет понимать каждое слово. Приложение — личный словарь
всех слов, которые произносит Гоенка, с озвучкой, русским переводом и
примерами из самих бесед. Работа со словарём — это **вычёркивание**: знакомое
скрывается, остаётся только то, что ещё надо выучить.

Второй смысл проекта — учебный: владелец (10+ лет C#/SQL/C++/TS) выбрал
стек, которого не знает, — **Go** — ради кругозора и рынка труда.

## 2. Как этим пользуются (со слов владельца)

1. Открывает сайт с ноутбука или телефона.
2. Видит список слов по алфавиту.
3. Знакомые слова скрывает иконкой **слева** от слова.
4. Незнакомые — нажимает иконку звука, слушает, читает русский перевод,
   запоминает.
5. Когда остаются трудные слова, нажимает кнопку рядом со словом и видит
   **фразы из бесед**, где оно встречается: на ноутбуке — во всплывающем окне,
   на телефоне — на отдельной странице.
6. Скрытые слова живут на отдельной странице, откуда их можно вернуть.
7. На обеих страницах — **нечёткий поиск** (терпит опечатки).
8. Состояние (что скрыто) хранится **у каждого пользователя на сервере** и
   одинаково на всех его устройствах, между сессиями.
9. Слова на **пали** входят в словарь: в латинской записи, со звуком и
   русским переводом.
10. Слово можно пометить как **важное**: оно уходит с главной страницы в
    отдельную группу на странице «Важные» (тоже с нечётким поиском); оттуда
    его можно вернуть в общий список или скрыть как выученное.
11. Сайт можно **запустить локально** одной командой — для отладки, без
    OAuth-ключей (вход «локально (dev)» только на `localhost`).

## 3. Цели, не-цели, анти-цели

**Цели**
- Полный словарь бесед: каждое произнесённое слово (в базовой форме) + пали.
- Озвучка, русский перевод, примеры из бесед со ссылкой на момент в видео.
- Скрыть / вернуть слово; синхронизация между устройствами; вход в аккаунт.
- Нечёткий поиск на главной и на странице скрытых.
- Удобно на телефоне.

**Не-цели (в первой версии)**
- Интервальные повторения, карточки, тесты, статистика прогресса.
- Другие языки перевода, кроме русского.
- Другие плейлисты/учителя (но пайплайн не должен этому мешать).
- Веб-админка для правки словаря — правки идут через файлы в репозитории.

**Анти-цели (провал, даже если «работает»)**
- Неверный смысл слов пали (буддийские термины переведены «по-бытовому») —
  хуже, чем отсутствие перевода.
- Потеря прогресса пользователя (скрытые слова пропали после обновления
  словаря или переезда сервера).
- Медленно или неудобно на телефоне.
- Опубликованы полные транскрипты бесед в публичном репозитории (авторские
  права Vipassana Research Institute) — см. §6.

| Модель сайта | Динамический, с учётными записями, состояние на сервере |
| Устройства | Ноутбук и телефон, одна адаптивная вёрстка |
| Примеры | Окно на широком экране, отдельная страница на узком |
| Пали | Входит в словарь: латиница, звук, русский перевод |
| Код | Отдельный публичный репозиторий на GitHub |
| Язык интерфейса | Русский (перевод — на русский) |

| Пользователи | По приглашению: вход через Google/GitHub, но зарегистрироваться может только адрес из списка `ALLOWED_EMAILS` (переменная окружения); снять ограничение — пустой список не означает «все», нужен явный `ALLOW_ANY=true` |
| Примеры и авторское право | Примеры **не в git**: `examples.jsonl` лежит в приватном бакете R2 и импортируется при деплое; на сайте не больше 3 фраз на слово; у самых частых слов (стоп-слова и верхний перцентиль частоты) примеров нет |
| Дохи на хинди и пение на пали | Исключены: такие отрезки находятся по определению языка Whisper и низкой уверенности распознавания и выбрасываются; пали попадает в словарь только как термины внутри английской речи |

## 5. Как устроено

Две независимые части в одном репозитории:

```
pipeline/  (Python, запускается вручную у владельца на ПК с GPU NVIDIA)
   YouTube ─▶ аудио ─▶ расшифровка с таймкодами слов ─▶ леммы + примеры
          ─▶ перевод (LLM) + глоссарий пали (ручная проверка) ─▶ озвучка mp3
          ─▶ dictionary/words.jsonl (в git)   +   mp3 ─▶ Cloudflare R2

app/       (Go, работает на Fly.io)
   words.jsonl ─▶ импорт в SQLite ─▶ HTML (templ) + HTMX ─▶ браузер
   пользователи, сессии, скрытые слова ─▶ та же SQLite ─▶ Litestream ─▶ R2
```

### 5.1 Пайплайн данных (Python)

| Шаг | Инструмент | Результат |
|---|---|---|
| Скачать аудио плейлиста | `yt-dlp` | `data/audio/*.m4a` (не в git) |
| Расшифровать с таймкодами слов | `faster-whisper` large-v3 на локальном GPU; в `initial_prompt` — список терминов пали | `data/transcripts/*.json` (не в git) |
| Леммы и формы | `spaCy` (`en_core_web_*`); слова пали сопоставляются с глоссарием до лемматизации | лемма → формы, частота, вхождения |
| Примеры | Для каждой леммы — до N (≈5) коротких фраз (≤ ~25 слов) с номером беседы и секундой | ссылки вида `youtu.be/<id>?t=<сек>` |
| Перевод | Claude API: лемма + 2–3 фразы контекста → 1–3 русских значения, часть речи, пометка | черновик перевода |
| Глоссарий пали | `pipeline/glossary/pali.yaml`: запись с диакритикой (`samādhi`), ASCII-вариант (`samadhi`), IPA, русское значение. LLM даёт черновик, **владелец проверяет вручную** | проверенный глоссарий |
| Термины Дхаммы на английском | `pipeline/glossary/dhamma.yaml`: обычные английские слова, которые Гоенка употребляет как термины (*sensation* = vedanā, *equanimity*, *craving*, *aversion*, *reaction*, *mind and matter*, *suffering*…). Тот же порядок: черновик LLM → проверка владельцем. Опора — глоссарий и русский перевод «Краткого изложения бесед» (VRI) | проверенный глоссарий |
| Ручные правки | `pipeline/overrides/*.yaml` — исправить перевод, скрыть мусорную лемму, склеить формы | применяются последними |
| Озвучка | Нейросетевой TTS с SSML; для пали — `<phoneme alphabet="ipa">` из глоссария | `audio/<slug>.mp3` → R2 |
| Сборка | — | `dictionary/words.jsonl`, одна строка на лемму, сортировка по лемме (удобно смотреть диффы в PR) |

Формат строки `words.jsonl` (ориентир, детали — строителю):

```json
{"key":"suffer","lemma":"suffer","lang":"en","pos":"VERB",
 "forms":["suffer","suffers","suffered","suffering"],"freq":412,
 "ru":["страдать","терпеть"],"note":null,"audio":"suffer.mp3",
 "examples":[{"talk":3,"t":1834,"text":"...you suffer, and you make others suffer..."}]}
```

`key` — **стабильный ключ** слова (нижний регистр, без диакритики). Пользовательские
данные ссылаются только на него, поэтому пересборка словаря не ломает прогресс.

### 5.2 Сайт (Go)

| Часть | Выбор |
|---|---|
| Язык | Go (актуальная стабильная версия) |
| HTTP | стандартный `net/http` с маршрутами вида `"POST /words/{key}/hide"` |
| Шаблоны | `templ` (типизированные, компилируются в Go) |
| Интерактивность | HTMX 2 (запросы и замена фрагментов) + Alpine.js (окно, проигрывание звука) |
| БД | SQLite (`modernc.org/sqlite`, без cgo), миграции `goose`, запросы через `sqlc` |
| Вход | OAuth Google и GitHub (`goth`), сессии `scs` в SQLite |
| Звук | `<audio>` из R2; если файла нет — запасной Web Speech API браузера |
| Поиск | индекс в памяти (см. ниже) |
| Хостинг | Fly.io, регион Сингапур, одна машина + том для SQLite |
| Бэкапы | Litestream → Cloudflare R2 (непрерывная репликация SQLite) |

**Данные.** Одна база SQLite: таблицы словаря (`words`, `forms`, `examples`)
наполняются командой импорта из `words.jsonl` (upsert по `key`, удаление
пропавших слов не трогает пользовательские записи); таблицы `users`,
`sessions`, `word_marks(user_id, word_key, mark IN ('hidden','important'), marked_at)`
— у слова не больше одной пометки на пользователя; нет строки — слово в общем списке.

**Страницы**
- `/` — все не скрытые слова по алфавиту; полоса букв A–Z (+ пали) для
  быстрого перехода; подгрузка порциями при прокрутке (`hx-trigger="revealed"`).
  Строка: [скрыть] **слово** [🔊] русский перевод · формы [примеры].
- `/important` — важные слова, тот же вид: слева «скрыть», справа «убрать из важных».
- `/hidden` — скрытые слова, тот же вид, слева кнопка «вернуть».
- `/words/{key}` — все формы слова, встреченные в беседах (*suffer, suffers,
  suffered, suffering*), и примеры из бесед со ссылками «смотреть с этого
  места» *(формы — пожелание владельца от 2026-11-07)*.
  На широком экране тот же фрагмент открывается в `<dialog>` поверх списка,
  на узком — обычный переход на страницу (работает и без JS).
- `/login`, `/logout`, OAuth-колбэки.

**Без входа** список, звук, переводы и примеры доступны; скрывать можно только
после входа — кнопка скрытия предлагает войти *(решение Claude)*.

**Нечёткий поиск.** Словарь статичен и мал (оценка 5–8 тыс. лемм), поэтому
индекс строится в памяти при старте: лемма, её формы, ASCII-вариант пали и
русские переводы. Ранжирование: точное → префикс → подстрока → расстояние
редактирования ≤ 1–2 (в зависимости от длины запроса). Поиск идёт по мере
ввода (`hx-trigger="input changed delay:200ms"`) и ограничен страницей:
на `/` — среди слов без пометки, на `/important` — среди важных, на `/hidden` — среди скрытых. Кириллица
поддерживается (поиск по переводу).

## 6. Ограничения

- **Авторские права.** Полные транскрипты и аудио — только в `data/`
  (в `.gitignore`). В публичный репозиторий и на сайт идут лишь словарь и
  короткие цитаты со ссылкой на официальное видео.
- **Ключи и секреты** (Anthropic, TTS, OAuth, R2) — только в переменных
  окружения / `fly secrets`, никогда в git.
- **Расходы:** Fly.io ~$2–5/мес; R2, Litestream — в бесплатном лимите;
  Claude API на перевод ~8 тыс. слов — единицы долларов разово; TTS — в
  бесплатном лимите провайдера (≈64 тыс. символов).
- **Учебный проект:** код должен быть идиоматичным Go, без «C# на Go»;
  комментарии там, где идиома Go неочевидна человеку с опытом C#.
- Пайплайн запускается вручную у владельца (нужен GPU); сайт от него не
  зависит в рантайме.

## 8. Отдано на усмотрение строителю

- Выбор TTS-провайдера (Azure Speech / Google Cloud TTS — оба умеют SSML и
  IPA) и голоса.
- Модель spaCy, точные пороги нечёткого поиска, размер порции подгрузки.
- Как отсечь мусор расшифровки (числа, междометия, обрывки) — через
  частоту, части речи и `overrides`.
- Структура пакетов Go, CI (GitHub Actions: `go test`, `go vet`,
  `golangci-lint`, `ruff`, `pytest`; деплой на Fly по мержу в `main`).
- Визуальный дизайн (спокойный, читаемый, тёмная тема по системе).

## 9. Решения Claude (владельцу проверить)

- Название репозитория `vipassana-vocab`, монорепо `pipeline/` + `app/`.
- Единица словаря — **лемма** с перечнем форм.
- Пали показывается с диакритикой (`paññā`), ищется и без неё (`panna`).
- Словарь хранится в git как `words.jsonl` и импортируется в SQLite.
- Просмотр списка, звука и переводов без входа разрешён; скрытие и
  **примеры из бесед** — только после входа (цитаты не отдаются анонимным
  посетителям и роботам).
- Озвучка заранее записанными mp3, а не синтезом в браузере.
- У каждой записи поле `reviewed`. Термины из глоссариев пали и Дхаммы, ещё
  не проверенные владельцем, показываются с пометкой «черновик перевода»;
  выпуск сайта проверки не ждёт. Обычные слова проверки не требуют.
