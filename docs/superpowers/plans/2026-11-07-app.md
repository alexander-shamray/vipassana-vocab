# Vipassana Vocab — сайт на Go: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сайт со словарём бесед: список слов по алфавиту, звук, перевод, примеры, скрытие/возврат слов на аккаунт пользователя, нечёткий поиск, вход по приглашению.

**Architecture:** Один Go-бинарник (`net/http` + `templ` + HTMX/Alpine), одна SQLite. Словарь импортируется из `dictionary/words.jsonl` (git) и `examples.jsonl` (приватный R2, в образ попадает при деплое) по стабильному `key`; пользовательские данные ссылаются только на `key`. Индекс нечёткого поиска строится в памяти при старте.

**Tech Stack:** Go ≥ 1.27, `github.com/a-h/templ`, HTMX 2, `modernc.org/sqlite`, `github.com/pressly/goose/v3`, `database/sql` с запросами вручную, `github.com/alexedwards/scs/v2` (+ `sqlite3store`), `github.com/markbates/goth`, `golang.org/x/text/unicode/norm`, Litestream, Fly.io.

**Spec:** `docs/superpowers/specs/2026-11-07-vipassana-vocab-design.md`

## Отступления при реализации (2026-11-07)

- **sqlc не используется**: его генератору на Windows нужен cgo; запросы написаны вручную на `database/sql` — их немного, и они рядом с кодом, который их вызывает.
- **Alpine.js не понадобился**: окно примеров и звук — 40 строк `static/app.js`.
- **Пометки — 200 с пустым телом, а не 204**: на 204 HTMX не делает замену, и строка не исчезала бы.
- **Нечёткий поиск — алгоритм Майерса** (битовый, до 64 символов запроса) вместо поклеточного Левенштейна: 4,8 мс на 8000 записей против 21 мс; простой Левенштейн остался в тестах как эталон.
- **`fly.toml` в корне репозитория**, а не в `app/`: контекст сборки образа — весь репозиторий (нужен `dictionary/`).
- **Без `Makefile`**: локальный запуск — подкоманда `go run ./cmd/server dev`, работает на любой ОС.
- **Пожелания владельца по ходу работы**: в окне примеров — все формы слова; локальный запуск с входом без OAuth; третий статус «важное» со своей страницей и поиском.

## Игры (добавлено 2026-11-07, реализовано в ветке `feat/games`)

Спецификация — §5.3 проектного документа. Сделано одной задачей:

- `internal/game` — проверка ответа: `CheckRussian(e, answers...)`, `CheckEnglish(e, answers...)`, `RussianPrompt(e)`; таблица тестов на скобки, «—», опечатки по длине, фразы и несколько вариантов распознавания.
- `internal/web/games.go` — `GET /games`, `GET|POST /games/write`, `GET /games/listen`, `GET /games/speak`, `POST /games/check` (JSON), `POST /games/important/{key}`; всё только после входа; 10 случайных слов без пометки «выучено» и с переводом.
- `views/games.templ` и `static/games.js` — письменная игра на HTMX; устные — Web Speech API (синтез и распознавание), с вводом текстом, если распознавания нет, и тайм-аутом 6 с на произнесение.
- Попутно: версии статических файлов по хэшу содержимого (`?v=`) и `Cache-Control: immutable`, иначе новый CSS не доходил до браузера; `[hidden]` сильнее любых `display`.

## Global Constraints

- Модуль: `github.com/alexander-shamray/vipassana-vocab/app`, всё под `app/`.
- SQLite без cgo: только `modernc.org/sqlite` (имя драйвера `sqlite`).
- Пользовательские таблицы ссылаются на слово только через `word_key TEXT`, без внешнего ключа на `words` — пересборка словаря не трогает прогресс.
- Вход: регистрация только для адресов из `ALLOWED_EMAILS` (через запятую, без учёта регистра и пробелов); пустой список = никто; `ALLOW_ANY=true` = все.
- На сайте не больше **3** примеров на слово; примеры видны только вошедшим пользователям (решение Claude: защита цитат от массового скачивания).
- Пометка непроверенного перевода терминов: текст «черновик перевода».
- Интерфейс на русском; HTML только через templ (автоэкранирование), никакого `template.HTML` из данных.
- Секреты только из окружения: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `SESSION_KEY`.
- Сгенерированный код (`*_templ.go`, `internal/db/sqlc/`) коммитится; CI проверяет, что генерация не даёт диффа.
- Идиоматичный Go: ошибки значением с `%w`, `context.Context` первым параметром, без глобального состояния, кроме `gothic.Store`.

## Review Focus

- Словарь пересобран, слово переименовано или исчезло → скрытые слова пользователя остаются в БД и возвращаются, когда слово снова появится (Task 3).
- `POST /words/{key}/hide` с несуществующим или пустым ключом → 404, не 500; повторное скрытие → 204, без дубля (Task 6).
- Текст примера с `<script>` или `&` → показан как текст, не исполнен (Task 7).
- Запрос поиска пустой, из пробелов, длиной 500 символов, в NFD-форме (`pañña`) или с `ё` → без паники; пустой запрос = обычный список (Task 4).
- Вход с адресом не из списка → страница «нет приглашения», пользователь не создаётся; адрес в другом регистре → пускает (Task 5).
