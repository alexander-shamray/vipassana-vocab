# vipassana-vocab

Словарь всех слов, которые произносит С. Н. Гоенка в беседах
[10 Day Vipassana Discourses (English)](https://www.youtube.com/playlist?list=PLPJVlVRVmhc4Z01fD57jbzycm9I6W054x):
по алфавиту, с озвучкой, русским переводом, всеми формами слова и примерами
из бесед со ссылкой на нужную секунду видео.

- **Словарь** — слова без пометок; слева 🗑 «выучено», справа ☆ «важное» и «примеры».
- **Важные** — отмеченные ☆; можно убрать из важных или скрыть как выученные.
- **Выученные** — скрытые слова; ↺ возвращает слово в словарь.
- На всех трёх страницах — нечёткий поиск (опечатки, без диакритики, по-русски).
- **Игры** — по 10 случайных невыученных слов: вписать перевод; услышать английское
  слово и сказать перевод вслух; услышать русское значение и сказать слово
  по-английски. Слова с ошибкой одним нажатием уходят в «Важные». Устные игры
  распознают речь средствами браузера (Chrome, Edge, Safari; в Firefox — ввод текстом).
- Пометки хранятся в аккаунте и одинаковы на ноутбуке и телефоне. Вход по
  приглашению через Google или GitHub.

## Устройство

| Папка | Что там |
|---|---|
| `app/` | Сайт: Go + templ + HTMX + SQLite. |
| `pipeline/` | Python: YouTube → расшифровка (Whisper) → леммы (spaCy) → перевод (Claude) → озвучка (Azure) → `dictionary/words.jsonl`. См. [pipeline/README.md](pipeline/README.md). |
| `dictionary/` | `words.jsonl` — собранный словарь, единственный результат пайплайна в git. |
| `dub/` | Go и Python: русская озвучка уроков для личного прослушивания. См. [docs/dub.md](docs/dub.md). |
| `docs/` | [Проектный документ](docs/superpowers/specs/2026-11-07-vipassana-vocab-design.md), [планы](docs/superpowers/plans/), [деплой](docs/deploy.md). |
| `testdata/` | Общие для Go и Python тестовые случаи нормализации текста. |

Полные транскрипты и аудио бесед в репозиторий не попадают (авторские права
Vipassana Research Institute). Публикуются только словарь; короткие цитаты
лежат в приватном хранилище и видны на сайте только вошедшим пользователям.

## Запуск на своей машине

Нужен Go 1.27+.

```bash
cd app
go run ./cmd/server dev
```

Откройте <http://localhost:8080>, нажмите «Войти» → «Войти локально (dev)».
Режим `dev` берёт базу `app/data/dev.sqlite`, загружает тестовые 30 слов из
`app/testdata/` (или настоящий `dictionary/words.jsonl`, если он уже собран) и
включает вход без OAuth. Этот вход работает только при `BASE_URL` на
`localhost` — на сервере его нет.

Подробная инструкция — запуск, проверка устных игр с микрофоном, телефон,
частые проблемы: [docs/local-run.md](docs/local-run.md).

Тесты и проверки:

```bash
cd app && go vet ./... && go test ./...
cd pipeline && pip install -e ".[dev]" && ruff check . && pytest
```

После правки `*.templ`: `go tool templ generate` (сгенерированные
`*_templ.go` коммитятся, CI проверяет, что они актуальны).
